# mALauncher

Лаунчер для Android (домашний экран), написанный на Kotlin + Jetpack Compose.
Минимальная версия Android: 8.0 (API 26).

## Что уже работает

- Назначается домашним экраном (HOME-интент в манифесте).
- Рабочий стол из нескольких страниц с горизонтальным перелистыванием и индикатором страниц.
- Часы и дата на рабочем столе.
- Долгое нажатие на пустое место → режим редактирования:
  - добавление и удаление страниц;
  - изменение числа колонок (3–6), иконки перераскладываются автоматически;
  - удаление иконок с рабочего стола кнопкой «×» (приложение не удаляется);
  - меню настроек.
- Док внизу экрана (до 4 приложений).
- Меню приложений (кнопка «Приложения»):
  - список всех запускаемых приложений;
  - секция «Избранное»;
  - автоматическая категоризация (Игры, Общение, Интернет, Мультимедиа, Инструменты, Система, Остальное) по категории приложения из Android и по ключевым словам в имени пакета;
  - ручная смена категории и исключение приложения из автокатегоризации;
  - поиск по названию и по имени пакета;
  - сортировка по алфавиту и по времени установки;
  - скрытие приложений (вернуть можно в меню настроек).
- Долгое нажатие на иконку (в меню, на рабочем столе, в доке) → действия: добавить/убрать с рабочего стола, избранное, док, скрыть, категория.
- Раскладка, избранное, скрытые приложения, категории и сортировка сохраняются после перезапуска (SharedPreferences, JSON).
- Список приложений обновляется после установки, удаления и обновления приложений.
- Светлая и тёмная тема (на Android 12+ — динамические цвета).

## Чего пока нет (запланировано)

- Перетаскивание иконок и создание папок перетаскиванием.
- Системный AppWidgetHost и собственные виджеты.
- Всплывающие виджеты.
- Движок обоев: параллакс по датчикам, размытие, разные обои для страниц.
- Настраиваемые жесты.
- Поиск по контактам, настройкам лаунчера и системным действиям.
- Настройки внешнего вида (шрифт, форма иконок, Icon Packs и т. д.).
- Переключатели анимаций.

Эти функции будут добавляться по этапам, каждый раз с проверкой сборки.

## Сборка APK

Проект расположен в папке `mALauncher/`. Для сборки локально нужны JDK 17 и Android SDK.

```bash
cd mALauncher
gradle :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`.

## Установка

1. Перенесите APK на телефон и установите.
2. Откройте настройки Android → Приложения → Приложение «Главный экран» и выберите mALauncher.

## Известные ограничения

- APK подписан debug-ключом; для публикации нужен собственный keystore.
- Не проверено на реальных устройствах в этой версии — перед использованием проверьте на своём телефоне.
